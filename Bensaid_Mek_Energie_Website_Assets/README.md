# Bensaid Mek Énergie — Website Asset Pack

This pack is prepared for direct use in a GitHub repository and for implementation by Claude Code or another frontend developer.

## Folder structure
- `logo/` — transparent approved logo lockups and mark
- `graphics/` — reusable SVG brand elements
- `images/` — web imagery cropped from the approved visual reference
- `references/` — final homepage, hero and graphical-charter references
- `styles/` — approved design tokens
- `docs/CLAUDE_BUILD_PROMPT.md` — full build prompt
- `docs/company-config.example.ts` — centralized company-information example

## Visual direction
Minimal, premium, spacious and restrained. The approved website direction uses orange, teal and charcoal only; **do not add blue**.

## Typography
- Headings/navigation: Montserrat
- Body/UI: Source Sans 3

Font files are intentionally not bundled. Load the fonts through your web stack/provider.

## Important
The raster logo files are supplied as transparent PNGs because they originate from the approved visual material. Keep their proportions intact and never recolor the primary logo.
For the hero, prefer `graphics/hero-ribbon.svg`, which is scalable and optimized for the final minimalist website composition.
